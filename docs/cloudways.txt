UDAAN LIVE — CLOUDWAYS DEPLOYMENT NOTES

CURRENT CERTIFIED LAYOUT

  public_html/udaan/
    Browser-facing front controllers, assets, service worker and .htaccess only.

  private_html/udaan/
    Application PHP, bootstrap, config, libraries and operational tooling.

  private_html/udaan-data/
    Persistent runtime data. DigiOps code releases must not overwrite this directory.

RECOMMENDED ENVIRONMENT

  UDAAN_ENV=production
  UDAAN_PUBLIC_URL=https://<your-stage-or-production-host>/udaan
  UDAAN_BASE_PATH=/udaan
  UDAAN_TRUST_PROXY_HEADERS=1
  UDAAN_DATA_ROOT=/absolute/path/to/private_html/udaan-data

  REDIS_ENABLED=1
  REDIS_HOST=127.0.0.1
  REDIS_PORT=6379
  REDIS_DB=0
  REDIS_REQUIRED=1   # use only where Redis is an explicit production dependency

CONTENT ADMIN

  UDAAN_CONTENT_ADMIN_KEY=<long-random-secret>

If the environment variable is not supplied, Udaan creates a protected key in the
persistent data root. Keep all runtime keys and content data outside the document root.

LEGACY ENCRYPTED-STORAGE MIGRATION

New encrypted writes use UDENC1 / AES-256-GCM. Existing historical plaintext records can
be read only while migration compatibility is enabled:

  UDAAN_LEGACY_PLAINTEXT_STORAGE=read

Dry-run the migration:

  php private_html/udaan/ops/migrate-legacy-storage.php

After a server snapshot, apply it:

  php private_html/udaan/ops/migrate-legacy-storage.php --apply --confirm-legacy-storage-migration

The migration creates backups under the persistent data root before rewriting records.
After a clean migration and preflight, disable legacy plaintext reads:

  UDAAN_LEGACY_PLAINTEXT_STORAGE=deny

Then run:

  php private_html/udaan/ops/preflight.php

HEALTH AND READINESS

  /udaan/health.php
    Public liveness only: app, version, timestamp and ok state.

  /udaan/ready
    Deployment readiness endpoint. Use it for operational checks.

Detailed health diagnostics are visible only to an authenticated Content Admin session.

RELEASE SAFETY

- Deploy only a certified digiops-release artifact.
- Verify the artifact source SHA matches the intended main commit.
- Never copy runtime keys, learner state, imported content or generated packs back into the code release.
- Keep private_html/udaan-data persistent across deploys and rollbacks.
- The production artifact does not publish the demo crowd-generation endpoint.
